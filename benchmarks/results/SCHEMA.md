# Benchmark Results Schema

This directory holds reproducible benchmark outputs. Per-seed CSVs are produced
by `run_benchmarks.py`; `aggregate.py` collapses them into `summary.csv`.

## Directory layout

```
benchmarks/results/
├── SCHEMA.md                 # this file
├── summary.template.csv      # column template (renders before real numbers exist)
├── summary.csv               # generated by aggregate.py (committed by a maintainer)
└── <scenario>/
    ├── seed_0.csv            # per-episode eval CSV for seed 0
    ├── seed_1.csv
    ├── seed_2.csv
    └── meta.json             # {"algorithm", "timesteps", "config"}
```

## Per-seed CSV (`seed_<n>.csv`)

These use the shared episode schema written by
`opengoalrl.utils.rollout.write_episode_csv`:

| Column        | Meaning                                          |
|---------------|--------------------------------------------------|
| `episode`     | 1-indexed evaluation episode                     |
| `reward`      | Total shaped reward for the episode              |
| `steps`       | Steps taken in the episode                       |
| `goals`       | Goals scored in the episode                      |
| `shots`       | Whether a shot was taken (0/1)                   |
| `ball_in_box` | Whether the ball entered the box (0/1)           |

(Tactical columns may also be present when evaluated with `--metrics tactical`.)

## `meta.json`

Non-episode metadata used by the aggregator:

```json
{"algorithm": "ppo", "timesteps": 50000, "config": "empty_goal_close.yaml"}
```

## Aggregated `summary.csv`

Generated by `aggregate.py`. Columns:

| Column              | Meaning                                                                 |
|---------------------|-------------------------------------------------------------------------|
| `scenario`          | Scenario name (matches the results subdirectory)                        |
| `algorithm`         | Training algorithm (from `meta.json`, default `ppo`)                    |
| `seeds`             | Number of seeds aggregated                                              |
| `timesteps`         | Training budget per seed (from `meta.json`)                             |
| `scoring_rate_mean` | Mean across seeds of the per-seed scoring rate (% episodes with a goal) |
| `scoring_rate_ci`   | 95% confidence interval half-width (normal approx; `0.0` for `<2` seeds)|
| `mean_reward`       | Mean across seeds of the per-seed mean episode reward                   |
| `sample_efficiency` | `scoring_rate_mean` per 1M timesteps (`0.0` when `timesteps` unknown)   |

### 95% CI definition

`scoring_rate_ci = 1.96 * std(scoring_rates, ddof=1) / sqrt(n_seeds)`

A normal approximation is used for simplicity (numpy-only, no SciPy). With fewer
than two seeds the CI is reported as `0.0`.
